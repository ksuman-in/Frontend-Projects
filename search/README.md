 ## Description
 This project is a simple React application that allows users to search for books using the Gutendex API. It features a responsive design, a search bar with debounce functionality, and displays search results in a card layout with image avatars.

 ## Features
 - Search bar with debounce functionality
 - Loading spinner while fetching results
 - Responsive design
 - Card layout for displaying search results
 - Image avatars for each book
 - Error handling for no results found

 ## Technologies Used
 - React
 - TypeScript
 - Tailwind CSS
 - Gutendex API
